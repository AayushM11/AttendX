# 👁️ AttendX — Face Recognition Attendance

AI-powered mobile attendance system with real-time face recognition.

## 🚀 Features
- Face recognition check-in with 5-angle enrollment
- OTP email verification for registration
- Attendance calendar with present/absent/leave tracking
- Leave management system
- Employee profile with work hours stats

## 🛠️ Tech Stack
`Python` `FastAPI` `Flutter` `OpenCV` `face_recognition` `PostgreSQL`

## ▶️ How to Run
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
